# BJ DESIGNS — Portfolio

A high-fidelity creative developer & brand design portfolio featuring an interactive 3D perspective tunnel slideshow, line-by-line text evaporate transitions, interactive tech archive with digital typewriter animations, and responsive mobile architecture.

## 🚀 Features

- **3D Perspective Tunnel Slideshow**: Continuous infinite Z-depth glides with reactive spring damping and cursor / scroll velocity tilt.
- **Home & Archive Routing**: Seamless directional curtain sweep view transitions with hash navigation (`#home`, `#archive`, `#about`, `#contact`).
- **Interactive Tech Archive**: Real-time typewriter write-up animations, number scramble lock-in, and radial ambient spotlight cards.
- **About & Contact Experience**: Evaporate line-by-line text reveals, minimalist scroll parallax, custom enquiry form, and direct contact dispatch.
- **Privacy Policy Modal**: Accessible, keyboard-friendly privacy policy overlay modal.
- **Zero-CLS Responsive Design**: Pre-calculated SSR hydration for smooth performance on mobile, tablet, and ultra-wide screens.

## 🛠️ Tech Stack

- **Core**: Vanilla HTML5, CSS3, Modern JavaScript (ES Modules)
- **Tooling**: [Vite](https://vitejs.dev/)

## 💻 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)

### Installation

```bash
# Clone the repository
git clone <your-repo-url>
cd new-portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
npm run build
```

To preview the production bundle locally:

```bash
npm run preview
```
